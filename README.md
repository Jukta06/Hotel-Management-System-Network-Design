# Hotel Management System Network Design

This project is a modern hotel network designed in Cisco Packet Tracer using VLANs, DHCP, WiFi, and OSPF routing.

## 📌 Features
- 3 Routers connecting 3 hotel floors  
- VLANs for different departments  
- DHCP for automatic IP assignment  
- OSPF for routing between floors  
- WiFi for laptops and mobile devices  
- Printers for each department  

## 🏨 Floor Details
- **1st Floor:** Reception, Store, Logistics  
- **2nd Floor:** Finance, HR, Sales  
- **3rd Floor:** Admin, IT  

## 🛠️ Technologies Used
- Cisco Packet Tracer  
- VLAN  
- Router-on-a-Stick  
- DHCP  
- OSPF  

## ✅ Result
- All departments connected through VLANs  
- Dynamic IP assignment working  
- Inter-floor communication successful  
- OSPF routing configured properly
